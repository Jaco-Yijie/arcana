# Arcana cinematic scenery

Twenty original, local SVG drawings authored for this project: one background and one transparent foreground for each of the ten registry IDs. No external images, embedded raster data, scripts, fonts or video downloads.

Edit the SVG paths directly; each uses a 1600 × 1000 viewBox. Composition concentrates on the left and leaves the right side quiet for Hero text. Profiles in `src/atmosphere/cinematic/profiles.ts` own URLs, palette, motion, texture, hero card selection and depth. The SVG artwork is independent of card artwork availability and does not replace missing tarot cards.

All SVG files together: 47,895 bytes. A future approved WebP/AVIF background or video with a local poster can replace the profile's discriminated `background` field. There are no active video profiles in V1.
