## 五、完整 Journey（浏览器实跑）

```
首页 → 选择牌组（古典）→ 问题输入 → Focus Moment → 选择牌阵
→ Prepare → 洗牌 ×3 → 切牌（第 45 张）→ 摊牌（78 张扇形）
→ 抽 3 张并逐张摆放 → 逐张翻开 → 选择解读模式（深度）
→ DeepSeek 真实解读 → 日记
```

全程通过。关键验证点：

| 检查 | 结果 |
|---|---|
| 每一步都由用户操作推进，没有系统代抽 | ✅ |
| 78 张扇形全部渲染（V1 曾出现空牌堆） | ✅ |
| 拖拽摆牌不卡死（V1 最严重的 bug） | ✅ 3 张全部成功 |
| 翻牌前所有卡背一致，不泄露牌面 | ✅ |
| 解读用的是真实 DeepSeek（`meta.provider = deepseek`） | ✅ |
| `meta.readingMode = deep` | ✅ |
| 解读里的牌与抽出的牌逐张一致 | ✅ |
| 流式渐进渲染（主题/整体能量先上屏） | ✅ |
| 等待时如实显示已等待秒数 | ✅ 「通常需要 1–2 分钟 · 已等待 77 秒」 |
| 界面无 Thinking / Token / DeepSeek / reasoning / 模型参数 | ✅ |
| 关系分析是真的关系，不是牌义罗列 | ✅ |
| 日记自动保存 | ✅ |
