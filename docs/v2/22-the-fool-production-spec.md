## 0. 语义层（五套完全一致，不可改写）

**愚者　The Fool**　`major-00`　major · 0

| | |
|---|---|
| 核心关键词 | 起点 · 未知 · 轻装 · 直觉 |
| 正位 | 愚者站在还没有路的地方，手上只有很少的行李。它描述的是一个尚未被定义的开始，条件不完备，但意愿是真实的。 |
| 逆位 | 逆位时，同样的轻装可能变成对细节的回避。此刻的「自由」有时是还没想清楚就先动了，也可能是明明想走却迟迟不肯迈步。 |

**四个符号（五套必须全部表达，可换物件、不可缺功能）**

- **悬崖边缘** —— 选择的临界点。往前一步是未知，但站着不动也不会更安全。
- **轻便的行囊** —— 带得少才走得动。这个阶段需要的不是万全准备，是可移动性。
- **未被踩出的路** —— 没有前人的脚印，也就没有必须遵守的走法。
- **白色的犬** —— 本能的提醒。它不阻止你，只是让你别忘了看脚下。

> 逆位不另出图。同一张原画 `rotate(180deg)` —— 因此**原画里不得烘焙任何文字与数字**，
> 否则倒过来就是倒字。牌名与编号一律由 `TarotCardFace` 绘制。

## 1. 技术规格（五套一致）

| 项 | 值 | 来源 |
|---|---|---|
| 卡牌宽高比 | `0.5999`（1 : 1.667） | `src/styles/theme.css --card-ratio` |
| master | 2160 × 3600 px | 交付尺寸 ×2，留返修余量 |
| full 交付 | 1080 × 1800 px · WebP | `paths.ts` 目录形状 |
| thumb 交付 | 240 × 400 px · WebP q72 | `THUMB_SPEC.card` |
| 出血 | 满幅。牌面 `object-cover`，画面即整张牌 | `CardArtworkLayer` |

**安全区** —— 代码会在原画之上画这两样东西：

- 顶部 **10%**：编号（罗马 / 阿拉伯，按各套 Bible）
- 底部 **14%**：牌名，且带一层由下而上的暗色渐变

因此主体的**头、手、核心象征必须落在纵向 10% – 86% 之间**。
底部 14% 可以有画面，但不能有必须看清的东西 —— 它会被压暗。

**1080 / 1800 = 0.6000**，与 `--card-ratio 0.5999` 一致（差 0.01%，肉眼不可见）。
不要按其它比例出图后再裁 —— 裁切会先吃掉边框和头顶。

## 2. 五套 Production Spec

## 月光　`legacy-moonlight`

> 一本在月光与薄雾里翻开的梦境插画集 —— 新艺术运动的流动曲线，画在会吸水的纸上，边缘全都化开了。

### 象征落位（Layer 1 的四个符号 → 这套牌怎么画）

- 悬崖边缘 → 只画石头的上缘轮廓，下方交给雾，不画深渊
- 轻便的行囊 → 挂在肩后的一个小布包，带子随风
- 未被踩出的路 → 雾里一道比周围略亮的窄带，从脚下延伸出去
- 白色的犬 → 一只白色的小型犬在左下角仰头，不吠、不阻拦，只是看着脚下

### Production Prompt（正向）

```text
【画种】一幅 透明水彩（湿画法为主） 的塔罗牌插画，竖构图。薄水粉提亮、极细银色墨线、半透明颜料叠层。表面质感：细纹水彩纸，纸纹只在放大时可见；颜料在边缘有自然的水痕。印刷性格：轻微的胶印网点，银线处有极淡的凸起感；整体像高级画册而非卡牌印刷
【主体】一个修长的年轻身影，侧四分之三背对观者，赤足，披一件会流动的薄纱
【瞬间】前脚已经离开崖边的石头，重心前倾，但还没有落下 —— 停在决定与后果之间的那一瞬
【取景】略微仰视的平视，人物略偏画面左侧，右侧留给雾。主体尺度：主体占画面高度约 55–70%，四周留出可呼吸的空
【前景】崖边几株低垂的白花，花瓣边缘化在水汽里；一小截行囊的带子垂下来
【中景】人物；脚下的岩石只画出上缘，下方直接溶进雾
【远景】大片月白的雾；右上方一轮被雾晕开的下弦月；没有地平线
【光】漫射月光，没有可指出的光源位置，无明确方向，略微偏上。对比：低。最亮与最暗之间跨度小。光穿过雾，边缘发生晕散；不产生硬阴影
【线条】极细，且宽度会随笔势自然变化。新艺术式的连续长曲线；一根线可以横跨大半张牌；避免直角与机械几何。边缘：化开 —— 轮廓线允许在雾里断掉、消失、再出现，不闭合是常态
【空间】三层：近处的织物或花、中景的人物、远处化在雾里的水面或月。留白：留白 ≥ 40%，且留白本身要有雾的层次，不能是空白纸。透视：弱透视，接近平视；空间靠明度层叠而不是线性透视。对称：非对称，重心略偏；但整体保持平衡
【人物语言】修长优雅，比例略微拉长；面部刻画克制，五官柔化但不省略；衣物是会流动的薄织物
【动物语言】安静的、不与人对视的动物：鹿、白鸟、猫；毛发边缘融进雾里
【自然语言】水、云、月、雾、开着的花、垂下的枝条；一切都在缓慢移动
【色彩】主色 月白象牙 / 雾蓝 / 淡薰衣草 / 柔银 / 冷灰；点缀 去饱和的玫瑰 / 极淡的暖金（面积 < 5%）。明度：五套里最亮。整体落在中高调，几乎没有真正的暗部；阴影用色相偏移而不是压暗
【情绪】一本在月光与薄雾里翻开的梦境插画集 —— 新艺术运动的流动曲线，画在会吸水的纸上，边缘全都化开了。 关键词：安静、通透、悬浮、柔和；像刚醒来还记得的那个梦；不催促；可以久看；看久了会松下来
```

## 古典　`legacy-classic`

> 一副被翻了很多年的古籍插画牌 —— 手绘墨线、有限水彩、象牙纸，纸面带着旧书的黄。它的价值感来自"实体"，不来自"神秘"。

### 象征落位（Layer 1 的四个符号 → 这套牌怎么画）

- 悬崖边缘 → 改为一道砌石的高台边沿，下方是一段看不见底的坡
- 轻便的行囊 → 系在木杖上，布料有织纹
- 未被踩出的路 → 远景丘陵间一道浅浅的痕，草还连着
- 白色的犬 → 旅人脚边，前爪抬起，仰头看他，不吠

### Production Prompt（正向）

```text
【画种】一幅 手绘墨线 + 有限水彩淡彩 的塔罗牌插画，竖构图。水粉点缀（面积极小）、铜版画式排线阴影。表面质感：暖象牙纸，纤维可见；墨线在纸上有轻微的吸收不匀。印刷性格：老式印刷颗粒；套色略有偏移（0.3mm 以内），这是它"是印出来的"的证据
【主体】一个背着行囊的年轻旅人，四分之三侧身，正抬脚跨过一道石阶
【瞬间】脚落在石阶外沿、还没踩实的那一步；他正回头看了一眼身后的犬
【取景】标准平视，两点透视，人物占画面高度约七成。主体尺度：主体占画面高度约 60–75%，构图饱满
【前景】石阶的边缘，砌缝清晰；阶前一丛小野花
【中景】旅人与犬；旅人手里一根木杖，杖头系着行囊
【远景】远处是一片起伏的丘陵与一条没有被踩出来的小径；天空用排线做出云
【光】室内单一暖光源（一盏灯 / 一扇窗），左上斜射，45° 左右。对比：中高。有明确的受光面与背光面。阴影用排线表现，不是灰色平涂；高光是留白，不是加白
【线条】中等，允许轻微的线宽变化 —— 那是手的痕迹，不是缺陷。闭合轮廓 + 排线（hatching）做体积；排线方向跟随形体。边缘：刻印 —— 线是压进纸里的，边缘清楚但不锐利；允许极轻微的抖动
【空间】完整的前中远景。RWS 的叙事原则在这里最强：每张牌都是一个场景。留白：留白 20–30%，主要在天空与地面。透视：传统单点或两点透视，规矩、可信。对称：轴对称与非对称并用，按牌义决定
【人物语言】传统插画比例，五官清晰可辨；服饰有具体的时代与材质（羊毛、亚麻、皮革）；手部要画对
【动物语言】写实但不照片化的动物：犬、马、鸟、蛇；有解剖依据
【自然语言】有植物学依据的树与花；山、云、水都有明确的形
【色彩】主色 象牙 / 焦橙 / 墨棕 / 灰蓝 / 暗驼；点缀 棕黑墨色 / 小面积暗酒红。明度：暖中调。纸是亮的，墨是深的，中间调由水彩承担；整体对比中等偏高
【情绪】一副被翻了很多年的古籍插画牌 —— 手绘墨线、有限水彩、象牙纸，纸面带着旧书的黄。它的价值感来自"实体"，不来自"神秘"。 关键词：沉稳、可靠、有年头、手工；像从抽屉深处拿出来的；想拿在手里翻；值得收藏；不炫技
```

## 森语　`legacy-forest`

> 植物学插画的精确 × 森林民间故事的温度。最重要的一条：**植物不是装饰，它本身就在讲牌义。**

### 象征落位（Layer 1 的四个符号 → 这套牌怎么画）

- 悬崖边缘 → 改为横倒的朽木：踩上去不知道会不会塌
- 轻便的行囊 → 藤编采集篓，编纹清晰
- 未被踩出的路 → 前方一片没有被踏过的蕨类，叶片完整
- 白色的犬 → 一只白色的狐，蹲在横木另一端，看着他的脚

### Production Prompt（正向）

```text
【画种】一幅 植物学水彩（干湿并用） 的塔罗牌插画，竖构图。水粉提亮、彩色铅笔细节、极细墨线勾形。表面质感：中粗纹水彩纸；颜料在纹理里沉淀出颗粒。印刷性格：接近博物图鉴的印刷：颜色准确、细节清晰、无网点感
【主体】一个背着藤编篓的年轻采集者，正抬脚跨过一根横倒的巨木
【瞬间】脚刚落在朽木上、苔藓被压下去的那一刻 —— 木头是空的，但还撑得住
【取景】低视角，接近地面；人物占画面中部偏右。主体尺度：主体占 50–70%；植物经常与人物同等重要，有时更重要
【前景】朽木上的苔与几丛小菌；一只被惊动的甲虫
【中景】采集者与横木；篓里露出几株刚采的植物
【远景】林间；一束叶隙光落在前方看不清的地面上；远处树干渐渐模糊
【光】穿过树冠的叶隙碎光，从上方偏侧射入，被打散成多个小光斑。对比：中等，但光斑与阴影的边界柔和。光在潮湿空气里形成可见的光柱；被照到的叶片半透明
【线条】细到中等，随枝条的粗细自然变化。有机曲线，绝不完全对称；叶脉、根系、菌褶都按真实生长逻辑画。边缘：有机 —— 边缘有轻微的不规则抖动，像手绘的植物标本
【空间】强纵深：近处的苔藓与菌、中景的人或动物、远处的林间光。留白：留白 25–35%，主要是林间的空气与光。透视：低视角居多（贴近地面），偶尔仰视树冠。对称：非对称为主；植物的生长方向决定构图重心
【人物语言】与森林有明确关系：在采集、在倾听、在被植物包围；衣物是天然材质，有磨损
```

## 3. 出图后的接入顺序

1. master → `1080×1800` WebP → `public/assets/decks/<deckId>/cards/major-00.webp`
2. 生成 `240×400` thumb → `.../thumbs/major-00.webp`
3. 在 `manifests.ts` 的 `BENCHMARK_STAGED` 里登记，**status 必须是 `benchmark`**
4. `npm run artwork:check` —— B 组会验证状态、路径唯一性、以及**文件真的在磁盘上**
5. `npm run dev` → `/dev/benchmark` 做 ROUND A–D 四轮比较
6. 人工评审通过 → status 改 `approved` → 这时 Deck Library 才会显示 1/78

> 第 6 步之前，正式产品里**看不到**这五张图。这不是保守，是 §13 的硬要求：
> benchmark 是试产，approved 才是交付。
