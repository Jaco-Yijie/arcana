## 0. 读这份文档之前必须先接受的四条

这四条不是建议，是上游架构已经用断言钉死的事实。Brief 里的每一句话都在它们之下。

### 0.1 语义层完全不动（G-16 / 18 号文 §2.2）

同一个 `cardId` 在 8 套牌之间：**牌名、编号、大小阿卡纳、花色、正位与逆位含义、
keywords、symbols 完全一致，一个字节都不许变。**

本文第三节的 40 段 Brief **只描述画面**。任何一段 Brief 都不构成对牌义的修改、
补充或倾向性暗示。特别是 `symbols`（如「悬崖边缘」「白色的犬」）属于 Layer 1，
它会进 Prompt，**8 套共用同一份**。各套牌在画面上怎么画这几个意象，是 Layer 2 的事，
与 `symbols` 数组本身无关。

> 换牌组后 AI Prompt 必须**逐字节相同** —— 这条断言是整个产品哲学的守门员。
> 一段 Brief 如果需要靠改 symbols 才能成立，那段 Brief 就是错的，改 Brief。

### 0.2 画面里不烘焙任何文字与数字

牌名、编号由 Layer 2 的 `typography` / `numbering` **在图上绘制**。
原画里出现任何字母、汉字、罗马数字、阿拉伯数字，一律退回。

两个理由：180° 旋转会出现倒字；以及**牌组一旦能自带文字，它就能自带给牌改名**
（把「死神」画成「转化」），那是 G-16 明令禁止的。

### 0.3 构图必须可 180° 阅读

**不存在 `-reversed` 资产。** 逆位是同一张原画 `rotate(180deg)`。

所以每张牌都要满足下面这套「双向构图规范」，本文第三节的每段 Brief 都按它写：

| 规则 | 具体做法 |
|---|---|
| 地平线居中 | 水平分界线放在画幅 **50% ± 8%**，上下两半各自成立 |
| 主体居中 | 主体质心落在纵向 **35%–65%** 区间内，不压边 |
| 弱重力 | 不用「人站在地上、天空在上」这种单向重力叙事；改用倒影、悬浮、水平带、对称轴 |
| 四角对称 | 四角装饰**二折或四折对称**；`cornerOrnament` 是代码画的，原画四角不要再画装饰 |
| 光源双读 | 光源尽量沿中轴或从两侧进，避免「只能从上往下照」的顶光 |
| 不可有单向文字性符号 | 箭头、指向性手势、单侧签名式笔触一律避免 |

> ⚠️ 这一条**无法自动断言**（18 号文 §13 明确承认这是最大缺口）。
> 交付验收时必须把每张图旋转 180° 再看一遍，两次都成立才算通过。

### 0.4 本文的「DeckVisualSystem」是文档概念，不是代码类型

第一节那张 12 字段表是**给美术看的世界观说明书**，
**不是** `DeckDefinition` 的新 schema。

`DeckDefinition` 的键**恰好是 7 个**（`deckId` / `kind` / `name` / `tagline` /
`description` / `visual` / `atmosphereId`），`deck:check` F 组按白名单断言，
多一个键即失败。本文里的 `artworkStyle` / `texture` / `motionLanguage` / `cover`
等字段**永远不要写进 registry.ts**。它们分别落在：

| 本文字段 | 真正的落地位置 |
|---|---|
| `cardFrame` / `typography` / `numberStyle` | `DeckVisualSpec.frame` / `.typography` / `.numbering`（已存在） |
| `cardBack` | `DeckVisualSpec.cardBack` + `back.webp` 资产 |
| `cover` | `cover.webp` 资产 |
| `artworkStyle` / `texture` | **只存在于原画本身**，代码里无对应字段 —— 这是刻意的 |
| `atmosphere` / `particles` / `surfaceColor` / `accentColor` | Layer 3 `atmosphere/registry.ts`（1:1 固定映射，不可自由组合） |
| `motionLanguage` | 只能用 `03-design-system.md` §5 已有的 motion token 表达，**不新增动画** |

| **numberStyle** | 建议 `roman` / `top`，但用**小型大写罗马数字**的视觉重量（细、小、贴近顶边），像书页的页码而不是章节号 |
| **artworkStyle** | **旧欧洲铜版画 / 木刻**。核心是**排线（hatching / cross-hatching）** —— 这是 8 套里唯一用排线造型的牌，明暗全部靠线密度而非色块。近乎单色（墨褐 + 象牙），彩色出现频率 < 10% 且只作为极小的点缀。人物是版画式的：程式化、扁平、比例略古怪、衣褶用线堆出来。加上手稿感元素：细密线描、古印章、边缘卷草花体、纸面的旧痕 |
| **atmosphere** | `parchment` |
| **surfaceColor** | 卡面 `oklch(0.905 0.024 84)` → `oklch(0.845 0.032 76)`（旧纸）；页面底 `oklch(0.140 0.014 48)` |

## 二、Cover Identity Brief

**硬要求：即使封面上没有任何文字，用户也必须能区分这 8 套。**
每套先给 brief，再给「唯一识别锚点」——那个只要看见就能定牌组的东西。

统一规格：`1024 × 1707`（1 : 1.667），WebP，< 220KB。
封面**不是任何一张牌**，所以它不受「可 180° 阅读」约束，但仍**不得烘焙任何文字**。

---

### 2.1 Ethereal 空灵

**构图**：单点式，极简。画幅正中偏上一道竖立的**发光门缝**——不是一扇门，是一道
从缝隙里透出来的竖直光带，宽度约画幅的 6%，高度约 45%，上下两端都化开在雾里。
门缝周围没有任何结构（没有门框、没有墙）——光从"什么都没有"的地方来。

**主体意象**：珍珠雾（pearl mist）· 发光门缝（luminous doorway）· 细小的天体点
（fine celestial points，8–12 个，随机但不成星座）· 通透大气。

**色彩**：`oklch(0.868 0.014 228)` 的珍珠雾为主，向上过渡到 `0.788 0.020 234`。
门缝的光是暖白 `oklch(0.94 0.020 96)`——**唯一的暖色，占比 < 3%**。

**材质**：无材质。柔光、渐变、极轻的镜头光晕。**禁止纸纹、噪点、颗粒**。

**留白策略**：留白占 **70% 以上**，8 套里最高。物体不是被放在空间里，而是从空间里
浮现出来的。边缘全部化开，画面四边不收边。

> **唯一识别锚点**：**竖直的一道光，四周全是雾，没有任何硬边界。**
> 它是 8 套里唯一「浅色 + 无框 + 无硬线 + 主体是光而非物」的封面。
> 与另外两套浅色封面（classic / legacy-classic）的区别：那两套都有明确的**硬线**
> （金几何 / 版画排线），空灵一根都没有。

---

### 2.2 Elysian 极乐之影

**构图**：完全对称的**闭合纹章式**。画面被一圈 Art-Nouveau 金线框完全封闭：
外框双线，四角向内收成弧，上下中点各有一个小的对称结点。框内正中一株
**对称的植物徽记**（茎从中轴升起，两侧叶片镜像展开，顶端一个几何化的花/星形）。

**主体意象**：深绿近黑的场（deep forest green / near black）· 古金线（antique gold）·
植物纹章（botanical crest）· 古典神秘学几何（圆中套方、六芒/八芒的构成骨架，
**只作为构图骨架，不画成符号**）。

**色彩**：底 `oklch(0.132 0.016 118)`（深橄榄近黑）；纹章金 `oklch(0.808 0.098 84)`；
过渡处一点暖苔绿 `oklch(0.352 0.050 100)`。**只有两个色相**：绿与金。

**材质**：亚光深色漆面上的**压印金箔**。金线有极细的暗边模拟凹陷，
局部有非常克制的旧漆龟裂（放大才看得见）。

**留白策略**：留白最少的一套（约 25%），但**留白全部集中在中心**——
装饰满在边缘，中心是空的。这就是「收藏感」：边缘越满，中心的空越值钱。

> **唯一识别锚点**：**一圈完全闭合、左右完美对称的金线装饰框。**
> 8 套里只有它的装饰**围成一个封闭的环**。
> 与「仙境之影」的区别写在 §5.1，一句话版本：**极乐是关起来的，仙境是打开一条缝的。**

---

### 2.3 Opaline 蛋白潮汐

**构图**：横向单带式。一条**潮汐曲线**（tidal curve）从左下缓缓升到右上，
贯穿整个画幅。曲线不是一根线，是一条宽度约画幅 30% 的**虹彩色带**，
带内有极细的同心波纹（像退潮后湿沙上的水纹）。带的上下各留一片安静的珠母面。

**主体意象**：珠母（mother-of-pearl）· 潮汐曲线（tidal curve）· 虹彩反射
（iridescent reflection）· 海洋几何（贝壳的对数螺旋、水波的正弦、
潮线的重复弧 —— 三种曲线共用一套数学）。

**色彩**：**8 套里唯一双色相同框**：青 `oklch(0.824 0.048 196)` 与
品红 `oklch(0.760 0.062 318)` 在同一条带上互相换位。粉金
`oklch(0.858 0.056 328)` 只在带的最亮处出现一小段。

**材质**：蛋白石 / 珠母 / 湿沙反光。表面有极浅的层状干涉纹。
**纪律**：虹彩的 chroma 上限 0.062，绝不允许滑向饱和彩虹（G-18 风险最高的一套）。

**留白策略**：留白 40%，全部是珠母面。留白本身也是有颜色的——它不是白，
是**会随角度换色的白**。

> **唯一识别锚点**：**同一条带上，颜色从青滑到品红。**
> 8 套里唯一在一个画面内出现两个相隔 120° 以上色相的封面。
> 也是唯一没有任何**直线或几何硬边**的封面（空灵没有硬线但也没有带）。

### 2.4 Wonderland 仙境之影

**构图**：**被拧歪的舞台式**。画面正中偏右一扇**歪斜的门**（向左倾 7°，
门框的透视是错的：左边框与右边框的灭点不一致）。门开着一条缝，缝里透出
不属于这个空间的光。门前方漂浮着一把**钥匙**（不指向门，刻意错开）。
门框与画幅边缘之间爬满**荆棘**。

**主体意象**：超现实门（surreal doorway）· 荆棘（thorn）· 漂浮的钥匙（floating key）·
一个**奇怪的天体符号**（strange celestial symbol —— 一个不合常理的发光体：
比如它有影子，或者它的光落错了方向。**不要画成月亮或太阳的写实形态**，
避免与牌名撞车）。

**色彩**：底 `oklch(0.138 0.026 322)` 深紫；门缝里的光是**绿金**
`oklch(0.822 0.064 148)`——这是 8 套里唯一的绿金，是整套牌最强的色彩签名。
荆棘用墨绿 `oklch(0.336 0.058 158)`。**紫与绿的对冲是它的身份**。

**材质**：剧场绘景。哑光蛋彩、干笔触、边缘有笔刷拖痕。
**禁止金属反光与亮面漆**（那是极乐之影的语言）。

**留白策略**：留白 30%，且**分布不均**——左侧空、右侧满，刻意不平衡。
暗角 0.50（全场最深），四周沉下去，只有门缝亮。

> **唯一识别锚点**：**透视是错的。**
> 8 套里唯一一个「你能看出这个空间画得不对，但说不上哪里不对」的封面。
> 具体到可验收的一句话：**门是斜的 + 钥匙悬空且不指向门 + 绿金的光。**

### 2.5 Classic 经典

**构图**：严格居中的**平衡几何**。象牙底上一个三层套合的徽记：
最外一个细金线圆环，中间一个内接的方，最内一个八角星。三层之间的间距相等，
整体占画幅高度的 45%，居中偏上 3%。上下各留一条干净的象牙带。

**主体意象**：象牙（ivory）· 细金线（fine gold line）· 平衡的中心几何
（balanced central geometry）· 永恒的塔罗结构（timeless tarot structure ——
圆/方/星这三个形状是塔罗最基础的结构语汇，不属于任何一副具体的牌）。

**色彩**：底 `oklch(0.916 0.026 86)` 象牙（全场最亮）；线 `oklch(0.772 0.110 74)`
（chroma 0.110，**全场最饱和的金**）；八角星内填一点**深酒红**作为唯一的第三色。

**材质**：**干净的厚纸 + 平版印刷**。纸有厚度（边缘微微压凹），
但**没有做旧、没有黄斑、没有磨损、没有排线**。印刷是均匀的、当代的。

**留白策略**：留白 55%，且**留白是干净的、有秩序的**——它是版式留白，
不是空气留白（对比空灵）。四边有明确的、可测量的边距。

> **唯一识别锚点**：**浅底 + 一个规整的金色几何徽记 + 一点酒红。**
> 与 `legacy-classic` 的区别（用户点名的风险）：
> **经典是干净的、有彩色的、用几何线；古典是脏旧的、近单色的、用排线。**
> 一眼判据：**看见排线就是古典，看见干净的几何线就是经典。**

### 2.6 Legacy Moonlight 月光

**构图**：上下二分的**倒影式**。画幅中线是水面。上半部一弯**新月**（偏左上），
月周围一圈完整的**银色轨道环**（细线画的椭圆，暗示月的运行轨迹）。
下半部是**静水**，水面上有月与轨道的倒影，倒影比实体暗 30% 且被水纹轻微打断。

**主体意象**：靛蓝（indigo）· 新月（crescent moon）· 银色轨道（silver orbit）·
静水（quiet water）。

**色彩**：底 `oklch(0.145 0.022 265)` → 卡面区 `oklch(0.240 0.045 258)`；
银 `oklch(0.870 0.022 248)` 是**主强调**（8 套里唯一以银为主的）；
金 `oklch(0.845 0.058 88)` 只在月的边缘出现一丝，占比 < 2%。

**材质**：夜色玻璃 + 银箔细线。表面光滑、有极浅的反光梯度。
**没有颗粒、没有纸纹**。银线是全场最细的（发丝级，0.5px 等效）。

**留白策略**：留白 60%，全部是夜空与水。**空间是负的**——
不是"有东西的地方"，是"什么都没有的地方"。

> **唯一识别锚点**：**一个银色的圆形轨道环。**
> 8 套里唯一出现**完整闭合圆环**的封面（极乐之影有闭合框，但是方的纹章框）。
> 加上：深靛蓝 + 水面倒影 + 银为主金为辅。

### 2.7 Legacy Classic 古典

**构图**：**手稿页式**。整个画面就是一页旧纸。四边有一圈由细密**版画排线**
构成的手稿边饰（不是几何框，是一圈手绘的卷草花体）。页面正中偏下一枚
**暗金压印的印章/蜡封**——它是画面里唯一的"实物"，有物理厚度与投影。
印章上方是一片留白的纸（暗示这里本该有文字，但按 §0.2 一个字都不能画）。

**主体意象**：陈年象牙纸（aged ivory）· 暗金（antique gold）· 旧印刷装饰
（old-print ornament）· 印章/雕版（seal / engraving）。

**色彩**：**近乎单色**。纸 `oklch(0.905 0.024 84)` → `0.845 0.032 76`；
排线是墨褐 `oklch(0.32 0.030 60)`；印章 `oklch(0.760 0.105 72)` 暗金。
**全画面只有三个明度层，没有第四种颜色。**

**材质**：**老纸纤维 + 凹版压痕**。可见的纸纤维、轻微黄斑、一道折痕、
边缘磨损。印章有真实的凹陷与侧光投影。8 套里材质最"脏"、年份感最重的一套。

**留白策略**：留白 45%，但**留白是"纸"而不是"空"**——它有纹理、有斑、有边。

> **唯一识别锚点**：**画面里有一枚实体印章（有厚度、有投影），四周是手绘排线。**
> 8 套里唯一出现**印章这个实物**、也是唯一使用**排线**的封面。
> 与 `classic` 的一眼判据（再强调一次）：**排线 = 古典，几何线 = 经典。**

### 2.8 Legacy Forest 森语

**构图**：**纵向单株标本式**。画面正中一株植物，从底部的**种子**与**根系**开始，
向上是茎，顶端展开叶片。整株植物占画幅高度的 75%，宽度只占 30%——
**极端的纵向比例**是它的构图签名。根系向下分叉的密度与叶片向上分叉的密度相当
（既是植物学的真实，也让画面上下平衡）。

**主体意象**：深绿（deep green）· 纵向植物符号（vertical botanical symbol）·
种子（seed）· 根的几何（root geometry —— 分叉遵循真实的植物分枝规律，
不是装饰性的藤蔓）。

**色彩**：底 `oklch(0.145 0.020 158)` 深墨绿；植物用墨线 + 苔绿
`oklch(0.350 0.055 152)`；种子处一点琥珀金 `oklch(0.830 0.070 84)`
（叶隙光的颜色），占比 < 5%。

**材质**：**植物标本纸上的墨**。纸有轻微纹理与吸墨感，线的边缘有极细的洇开。
**没有金属、没有反光、没有漆面。**

**留白策略**：留白 55%，集中在植物两侧。左右两条空带是刻意的——
标本图的语言就是"把一个东西孤立出来看"。

> **唯一识别锚点**：**一株从种子长到叶的纵向植物墨线图，根系和叶片一样详细。**
> 8 套里唯一出现**根系**、也是唯一采用**极端纵向单主体**构图的封面。
> 与极乐之影（也是绿）的区别：极乐的植物是**装饰化、对称、金线勾边、围成框**；
> 森语的植物是**写实、单株、墨线、居中**。

### 2.9 八套封面识别锚点速查

| deckId | 唯一识别锚点（一句话） | 最快判据 |
|---|---|---|

## 三、代表牌 Artwork Brief（8 套 × 5 张 = 40 张）

### 3.0 全局约束（每张都适用，验收时逐条对照）

1. **语义完全共享**：同一 `cardId` 的牌义、正逆位含义、keywords、`symbols`
   在 8 套之间**完全一致**。本节只描述画面，**不得改动、暗示或补充任何语义**。
2. **不烘焙文字与数字**：牌名与编号由代码绘制（`typography` / `numbering`）。
3. **可 180° 阅读**：逆位 = 同一张图 `rotate(180deg)`。按 §0.3 的双向构图规范执行。
4. **不存在 `-reversed` 资产**。
5. **四角不画装饰**：`cornerOrnament` 由代码绘制，原画四角留给它。
6. **同一模特，八组照片**：这 5 张是横向对比的对照组，
   **变量必须只有画风**。不允许某套牌把某张画得更"重要"。

**5 张共用的 Layer 1 symbols**（8 套都必须画到，不多不少）：

| symbol | 风险 | 通用解法 |
|---|---|---|

### 3.1 `ethereal` 空灵 · 5 张

> **本套独有识别特征（5 张都要有）**：没有闭合轮廓线 · 边缘全部化开 ·
> 留白 ≥ 60% · 有一处「光从没有来源的地方来」 · 人物有当代的、可读的情绪。

**`major-00` The Fool**
主体：一个当代装束的年轻人**侧身站在中线的断口上**，重心是放松的；
脚边一只白色的犬（同样柔化，几乎只是一团亮）；肩上一个很小的布包。
构图：断口横贯中线，断口上下都是雾，看不出哪边是"下面"；人物在中线偏左，
质心在纵向 48%。「未被踩出的路」画成雾里几道**更亮的空白**，不画成地面上的痕迹。
光源：无来源的柔光从人物背后透过来，人物边缘发亮。
色彩：珍珠灰蓝为主，人物衣服是稍暖的白。
装饰：无。四角完全空。
识别：**人是半透明的**——衣服的边缘和雾是同一个色值。

**`major-01` The Magician**
主体：一个人在一张**悬浮的桌面**前，一手上举。桌上四件元素器物
（杯 / 剑 / 星盘 / 权杖）柔化到只剩剪影。头顶上方一个**无限符号**，
它不是画上去的线，是**两团光晕重叠**形成的横 8 字。
构图：桌面在正中，桌下有一模一样的一层光晕（不是倒影，是"桌子在雾里的另一半"）；
上下对称。
光源：光从桌面本身发出，向上向下同时扩散。
色彩：雾灰蓝 + 桌面处的一小片暖白。
装饰：无。
识别：**无限符号是光晕重叠出来的，不是一根线。**

**`major-02` The High Priestess**
主体：正面对称。两根柱子只画成雾里两道**更暗的竖带**（不画柱头柱础）；
柱间一层帷幕，薄到能透出后面的光；一位女性坐姿，膝上一卷卷轴；
胸前一弯新月（同样是光晕，不是线稿）。
构图：完美左右对称，轴在画幅正中。帷幕下缘与静水的水面在同一条中线上重合——
上半是帷幕，下半是水中的帷幕。
光源：从帷幕后方均匀透出。
色彩：8 套里最接近无色的一张，只有明度变化。
装饰：无。
识别：**帷幕薄到能看见后面**——这套牌不隐藏东西，它只是让东西不那么清楚。

**`major-13` Death**
主体：一列人影**横向缓慢穿过画面中线**（3 个，剪影级柔化，不朝向任何一端）；
队首一面黑色旗帜（旗面是雾里最暗的一块）；地上一朵白玫瑰；
远处地平线上两座塔的轮廓，淡到几乎看不见。
构图：地平线在正中，队列在地平线上；地平线下方是同一片雾（不是地面）。
光源：正面均匀的冷白，没有戏剧性。
色彩：这套牌里唯一出现"黑"的一张，但那个黑是 `oklch(0.30)` 的雾黑，不是纯黑。
装饰：无。
识别：**没有任何恐怖元素，连骨骼都没有**——死神在这套牌里是一次安静的搬家。

**`major-17` The Star**
主体：中线上一片静湖；水边一个跪姿人物，双手各持一瓶，水从两瓶同时倾出，
一注入湖一注入岸；天上一颗八角星，湖里一颗一模一样的倒影八角星；
夜色中一只鸟的剪影，飞在两颗星之间的中线上。
构图：**8 套里对称度最高的一张**。水面在正中，天与水互为镜像。
光源：星光。它是这张画里唯一的光源，但强度很低。
色彩：最大面积的留白（湖面 + 天空占 70%）。
装饰：无。
识别：**天上和水里的星一样亮**——分不清哪个是真的。

### 3.2 `elysian` 极乐之影 · 5 张

> **本套独有识别特征**：匀速闭合的新艺术曲线 · 金线勾边 · 平涂色块 ·
> 人物静态仪式化 · 装饰围合在画面边缘且**完全对称**。

**`major-00` The Fool**
主体：一个身着长袍的人物**正面站立**在中线的石阶断口上，双手自然垂下；
身侧一只白犬（侧影，装饰化处理，尾巴曲线是新艺术式的）；
腰间挂一个金线勾边的小囊。
构图：中轴对称。断口是一道横贯的石缝，缝上缝下各有一段石阶——
上下的阶数相同。「未被踩出的路」是石面上一条**没有磨损痕迹**的浅色带。
光源：从画面上方偏右斜进来的暖金光，落在石面与袍褶上；阴影很长但不冷。
色彩：深橄榄底 + 暖苔绿 + 古金勾边。
装饰：画面左右两侧各一条从底部升起的对称藤蔓，在顶部相接成一个尖拱。
识别：**藤蔓在画面顶部接成一个完整的拱**——装饰把主体关在里面。

**`major-01` The Magician**
主体：人物立于一张厚重的石桌前，右手高举权杖；桌上四件器物按**左右对称**排列
（杯与星盘一组、剑与另一支杖一组）；人物头顶一个**由两条藤蔓交缠而成的无限符号**。
构图：中轴对称。桌面在正中，桌下是一段有装饰浮雕的石座（不是空的）。
光源：右上斜光，落在举起的手与桌面边缘上，金属反光是硬的。
色彩：桌面深橄榄，器物古金，袍子暖苔绿。
装饰：桌面前缘一条希腊回纹式的金线带。
识别：**无限符号是两条真实的藤蔓交缠出来的**（对比空灵的光晕、经典的几何线）。

**`major-02` The High Priestess**
主体：两根**完整的新艺术石柱**（柱头是风格化的叶形），柱间一幅厚重的织物帷幕，
帷幕上织有对称的植物纹；女性坐姿正中，膝上卷轴用金线绑扎；
头饰上一弯金色新月。
构图：绝对左右对称。帷幕下缘垂到画幅中线，中线以下是一池静水，
水中映出帷幕的下半段与柱脚。
光源：柱间从后方透出的暖光，把帷幕照出织物的厚度。
色彩：8 套里这张最"重"——深橄榄近黑 + 大面积古金。
装饰：柱身上的对称藤蔓浮雕。
识别：**帷幕是不透的**（对比空灵的透）——这套牌明确地"藏东西"。

**`major-13` Death**
主体：一列披袍的行进者**横穿画面**，队列在中线上，不朝向任何一端；
队首一面黑色旗帜，旗面上有金线织出的对称植物纹；
前景地面一朵白玫瑰（是全画唯一的纯白）；远处对称的两座塔。
构图：双塔左右对称地立在地平线两端，地平线在正中；地平线下是石地的一段剖面
（有根、有石层），所以下半部不是空的。
光源：斜射的暖金落日光，把行进者的影子拉得很长（影子横向，不纵向）。
色彩：深橄榄 + 黑旗 + 一点白玫瑰 + 金。
装饰：画面上下边缘各一条对称的金线带。
识别：**旗子上有织纹**——连死亡在这套牌里都是被装饰过的。

**`major-17` The Star**
主体：中线是一池静水，水边一位跪姿人物双手持瓶倾注；
天上一颗几何化的八角星（金线画的，边缘锐利）；水中一颗对称的倒影星；
一只鸟的装饰化侧影停在画面右侧的藤蔓上。
构图：中轴对称 + 上下镜像。
光源：星是画面里的实际光源，光呈放射状的金线。
色彩：深橄榄水面 + 古金星光。
装饰：画面两侧对称的芦苇/藤蔓，在顶部不相接（与愚者的相接形成变化）。
识别：**星是画出来的几何形，边缘锐利**（对比空灵的光晕、蛋白潮汐的色带）。

### 3.3 `opaline` 蛋白潮汐 · 5 张

> **本套独有识别特征**：整张画是一片连续流动的表面 · 没有闭合轮廓线 ·
> 青与品红在同一画面内换位 · 主体与背景的界限被色带打通。

**`major-00` The Fool**
主体：一个人形从画面中线的**色带断口**边缘往外走；犬是一团更亮的珠白，
形态半融进色带；行囊是色带上一个凝聚起来的结。
构图：断口是一条横贯的**色相断层**——断口左侧的带是青，右侧是品红，
断口本身是两色最激烈换位的地方。「未被踩出的路」是带上一段**没有波纹**的平滑区。
光源：整片表面自发的柔光，没有方向。
色彩：青 `196` ↔ 品红 `318`，在同一条带上完成一次完整换位。
装饰：无独立装饰，波纹本身就是装饰。
识别：**悬崖不是地形，是颜色的断层。**

**`major-01` The Magician**
主体：桌面是一片**水平的反光面**（像退潮后的湿沙），四件器物半陷在里面，
只露出一半轮廓；人物的上举手臂从桌面的反光里长出来；
无限符号是**桌面反光形成的两个环**。
构图：桌面在正中，桌面上下的反光互为镜像，上下都成立。
光源：反光面自己在发光。
色彩：桌面青，器物处泛品红。
装饰：同心波纹。
识别：**器物一半在表面里、一半在表面外。**

**`major-02` The High Priestess**
主体：双柱是两道竖直的**色带**（青带与品红带各一），中间的帷幕是一层
半透明的虹彩膜；人物形体由流动的色带构成；新月是膜上一处更亮的弧；
卷轴是一个卷起的色带端头。
构图：左右对称，中线是帷幕。帷幕下缘与静水面重合。
光源：膜的干涉光。
色彩：两根柱子是**不同色相**——这是全套最强的一次青/品对置。
装饰：无。
识别：**两根柱子颜色不一样。**

**`major-13` Death**
主体：一列形体横向穿过中线，它们不是人，是**色带上凝聚出来的密度**；
黑旗是画面里唯一一处色相消失的地方（灰）；白玫瑰是一个纯珠白的漩涡；
双塔是地平线上两处色带的垂直隆起。
构图：地平线 = 潮线，在正中；上下互为反射。
光源：无方向。
色彩：整张画是青向品红过渡的一次完整迁移，黑旗打断它。
装饰：无。
识别：**黑旗是"颜色消失了"，不是"画了一块黑"。**

**`major-17` The Star**
主体：静湖是整张画的主体，占 70%；八角星是水面上方一处虹彩最强的**干涉斑**
（不是画出来的星形，是八条方向的反光交汇）；倾注的双瓶是两股从上方落下的
色带，一股青一股品红，落入湖面时激起同心波纹；鸟是水面上一道飞过的暗痕。
构图：水面在正中，上下镜像。
光源：干涉。
色彩：这张是全套虹彩强度的上限（chroma 仍 ≤ 0.062）。
装饰：无。
识别：**星不是一个形状，是八个方向的反光。**

### 3.4 `wonderland` 仙境之影 · 5 张

> **本套独有识别特征**：至少一处**尺度错误** + 一处**透视错误** ·
> 强侧光与深阴影 · 绿金作为唯一暖色 · 荆棘从卡框内侧长进画面。

**`major-00` The Fool**
主体：一个人物站在**一段悬空的、不知从哪来也不知到哪去的楼梯**的断口上；
一只白犬站在楼梯下方的空气里（没有支撑）；行囊漂浮在人物身后，
没有系在身上。
构图：断口在中线。楼梯的透视是错的——上下两段台阶的灭点不一致，
所以旋转 180° 之后它"依然错着，而且错得同样自然"。
「未被踩出的路」是空气中一串**微微发亮的台阶轮廓**，还没实体化。
光源：从右侧极低的角度打进来，人物投下一道长到出画的影子（横向）。
色彩：深紫底 + 绿金的光 + 墨绿的荆棘。
装饰：荆棘从画幅左右两侧内侧长进来约 15%，二折对称。
识别：**犬站在空气里，而它自己毫不在意。**

**`major-01` The Magician**
主体：桌子**比人高**（尺度错误）；人物必须举高手臂才够得到桌沿；
桌上四件器物大得不合理（杯有半人高）；无限符号是桌子上方一圈
**自己咬住自己的荆棘**。
构图：桌面在中线。桌子下方是一片同样有内容的空间——另一套倒置的器物影子。
光源：从桌面下方往上打的绿金光（光源位置本身就是错的）。
色彩：深紫 + 绿金。
装饰：荆棘。
识别：**光从桌子底下来。**

**`major-02` The High Priestess**
主体：两根柱子**一根比另一根高**（不对称，但通过帷幕的斜度让画面重新平衡）；
帷幕是一面镜子，镜子里映出的房间**比外面大**；人物坐在镜前，
镜中的她手里有卷轴，镜外的她手里没有；新月挂在镜子内部（不在真实空间里）。
构图：中线是镜/帷幕的下缘 = 水面。镜里的静水与镜外的静水连成一片。
光源：镜内的光比镜外亮。
色彩：深紫 + 一小片绿金（只在镜里）。
装饰：荆棘沿镜框内缘。
识别：**镜里有的东西，镜外没有。**

**`major-13` Death**
主体：一列行进者**横穿画面**，但队伍中间有一个位置是空的（有影子没有人）；
黑旗的旗面朝向与风向相反；一朵**大得离谱**的白玫瑰占据前景约 25%
（尺度错误）；地平线上双塔一高一矮，且矮的那座的影子比高的那座长。
构图：地平线在正中；地平线下方是同一队人的倒影，但倒影里那个空位是有人的。
光源：低角度侧光，绿金。
色彩：深紫 + 黑 + 一朵极大的白 + 绿金。
装饰：荆棘。
识别：**队伍里少一个人，但倒影里不少。**

**`major-17` The Star**
主体：静湖；八角星**有影子**（一个天体不该有影子）；倾注的双瓶悬在空中，
没有人拿着；水注落到一半就消失了；一只鸟停在水面上（不是浮着，是站着）。

## 四、Deck ↔ Scene 一致性规则

**要解决的问题**：「场景一套设计、牌面另一套设计」。
用户在牌桌上同时看见的东西有四层：页面氛围（Layer 3）· 卡背 · 卡框（代码画的）·
牌面原画。这四层必须是**同一种材质在不同尺度上的表现**。

### 4.1 一条总规则

> **卡框是牌面原画的"物理边界"，卡背是牌面原画的"背面"，
> 氛围是这张牌所在房间的"空气"。**
> 三者与原画共用同一套：**线条语言、材质、光源逻辑、色相集合**。

四个可验收的对齐点：

| 对齐点 | 检查方法 |
|---|---|
| **线条语言** | 卡框的 `inlay` / `cornerOrnament` 与原画里的线**粗细同级、笔性同源** |
| **材质** | 卡背的表面材质与原画的表面材质**必须是同一种**（纸不能配漆面） |
| **光源** | 氛围的 `layers.shape` 光源方向与原画的主光方向**不矛盾** |
| **色相集合** | 原画用到的色相**必须是**该套 `themeVars` 已有色相的子集（±10°） |

### 4.2 逐套对齐表

| deck | 线条语言（框↔画） | 材质（背↔画） | 光源（氛围↔画） | 色相集合 |
|---|---|---|---|---|
| `ethereal` | 框 0.5px 几乎不可见 ↔ 画无闭合轮廓线。**两边都在"不画线"** | 卡背无材质柔光 ↔ 画无材质柔光 | `veil-light` 雾从下往上抬、中段最亮 ↔ 画的光都来自"没有来源的地方"，不给方向 | 228–234 单色相带 + 96 暖白点 |

### 4.3 三条禁止

1. **禁止跨套借材质**。森语不能出现漆面，极乐不能出现纸纤维，
   经典不能出现排线，古典不能出现平涂色块。这四条是 §5 区分度的物理基础，
   借一次就塌一次。
2. **禁止原画自带边框**。卡框由 `CardFrame` 代码绘制。原画画了框
   = 双层框 + 四角撞车 + 180° 后不对齐。
3. **禁止用氛围去补救牌面**。如果一张牌只有配上它的氛围才好看，
   那张牌就是不合格的 —— 日记回看、分享卡、Deck Library 预览都会把它单独拿出来看。

### 4.4 `particles` 不承担区分职责（一条必须承认的现实）

8 套的 `particles` 取值只有 4 种，而且有重复：

| particles | 用在哪几套 |
|---|---|
| `static-motes` | `ethereal` · `wonderland` · `legacy-forest` |
| `static-dust` | `elysian` · `classic` · `legacy-classic` |
| `static-stars` | `legacy-moonlight` |
| `none` | `opaline` |

**结论**：粒子**不是**区分维度，它只是氛围的一个质感开关
（且受移动端功耗约束，不做 canvas 逐帧）。真正的区分由
`layers`（三层渐变的光源结构）+ 卡面色 + 原画材质承担。
**不要为了"让 8 套都不一样"去扩充 `particles` 的枚举** ——
那会把功耗成本换成一个用户根本分不出来的差异。

### 4.5 `motionLanguage` 的边界

8 套的动效"性格"**只能用 `03-design-system.md` §5 已有的 token 表达**：
`--ease-drift` / `--ease-settle` / `--ease-enter` / `--ease-exit` /
`--duration-tap 90` / `--duration-base 260` / `--duration-flip 520` /
`--duration-settle 620`。

**明确禁止**（G-08 + 设计系统 §1 的三条硬规则）：
弹跳 spring · 爆炸粒子 · 大量闪光 · SSR 抽卡表现 · 选中态 glow ·
任何超过 520ms 的交互动画。

牌组之间可以真实差异的动效变量只有三个，都已存在：
`atmosphere.layers.driftOpacity`（雾强度）· `layers` 三层渐变的空间分布 ·
`frame.vignette`（暗角深度带来的"落定重量感"）。
**其余的"动效性格"只是给美术与前端的共同语汇，不落成新代码。**

### 5.1 高风险对：`elysian` 极乐之影 ↔ `wonderland` 仙境之影

**风险来源**：名字里都有「影」；都是暗底；都有植物类装饰；`obsidian` 与 `thicket`
的 `bg-void` 亮度接近（0.132 / 0.138）。

**六维比对 —— 6/6 全不同**：

| 维度 | 极乐之影 | 仙境之影 | 拉开了吗 |
|---|---|---|---|
| 主色相 | 112–118 橄榄绿 + **黄金 84** | 320 紫 + **绿金 148** | ✅ 相隔 200° |
| 卡面明度 | 0.238 → 0.352 单向变亮 | 0.222 → 0.336 但**跨色相对冲** | ✅ 一个是同色相渐变，一个是紫↔绿对冲 |
| 材质 | 亚光漆 + **金属反光** | 哑光蛋彩 + **禁止反光** | ✅ 直接对立 |
| 线条 | **匀速、闭合、对称** | **尖锐、断续、歪斜** | ✅ 直接对立 |
| 构图密度 | 留白 25%，装饰在边缘围合 | 留白 30%，**分布刻意不均** | ✅ 一个对称一个失衡 |
| 装饰母题 | 藤蔓 leaf · 闭合纹章 | 荆棘 thorn · 门 · 钥匙 | ✅ `cornerOrnament` 就已不同 |

**一句话判据**：
> **极乐之影是关起来的，仙境之影是打开一条缝的。**
> 极乐的装饰**围成一个封闭的环**，透视是正确的，光是暖金的；
> 仙境的装饰**从边缘长进画面里**，透视是错的，光是绿金的。

**再补一条美术可以直接执行的机械规则**：
极乐之影的每张画**必须左右对称**（轴在正中）；
仙境之影的每张画**必须至少有一处明确的不对称或透视错误**。
这两条互斥，一眼可判，且可人工验收。

### 5.2 高风险对：`classic` 经典 ↔ `legacy-classic` 古典

**风险来源**：名字几乎一样；**两套的 `themeVars` 几乎相同**（见下）；
都是浅色卡面 + 暗金；`oldroom` 与 `parchment` 是全 10 套里最接近的一对氛围。

**先说一个必须承认的事实 —— Layer 3 区分不了这两套**：

| token | `classic` (oldroom) | `legacy-classic` (parchment) | 差值 |
|---|---|---|---|
| `--color-card-sky-a` | `oklch(0.916 0.026 86)` | `oklch(0.905 0.024 84)` | ΔL 0.011 · Δh 2° |
| `--color-card-sky-b` | `oklch(0.852 0.034 78)` | `oklch(0.845 0.032 76)` | ΔL 0.007 · Δh 2° |
| `--color-gold` | `oklch(0.772 0.110 74)` | `oklch(0.760 0.105 72)` | ΔL 0.012 · Δh 2° |
| `--color-bg-void` | `oklch(0.128 0.016 56)` | `oklch(0.140 0.014 48)` | ΔL 0.012 · Δh 8° |
| `particles` | `static-dust` | `static-dust` | 相同 |

**这些差值全部低于人眼在非并排条件下的可辨阈值。**
所以：**这两套的区分度 100% 由 Layer 2（原画 + 装帧）承担，
Layer 3 一点忙都帮不上。**

> 这不是缺陷，而是必须写进验收标准的事实：
> **如果这两套的原画风格没拉开，它们就是同一套牌。**
> 建议追加一条人工验收项：把两套的 5 张代表牌**去掉卡框、去掉背景**并排看，
> 仍然能一眼分出来，才算通过。

**六维比对 —— 4/6 不同（②主色相、②明度 不算数）**：

| 维度 | 经典 | 古典 | 拉开了吗 |
|---|---|---|---|
| ① 主色相 | 74–86 | 76–84 | ❌ **几乎相同** |
| ② 卡面明度 | 0.92 | 0.85–0.91 | ❌ **几乎相同** |
| ③ 材质 | **干净厚纸 + 平版印刷**，无做旧、无黄斑 | **老纸纤维 + 凹版压痕**，有黄斑折痕磨损 | ✅ 直接对立 |
| ④ 线条 | **均匀中粗描边 + 平涂色块** | **排线 hatching**，无平涂 | ✅ 直接对立 |
| ⑤ 构图密度 | 中，象征物边界清晰、彼此分离 | 高，排线铺满，象征物嵌在线里 | ✅ |
| ⑥ 装饰母题 | 几何徽记（圆/方/星）· fleuron 粗 2px | 印章/蜡封 · 卷草手稿边饰 · 细密多层 | ✅ |

**追加的第七维（专为这一对设立）—— 彩色饱和度**：

| | 经典 | 古典 |
|---|---|---|
| 彩色占画面比例 | **≥ 60%**，每张有一个明确主色（黄/红/深蓝/深灰蓝/青绿） | **< 10%**，近乎单色 |

**一句话判据**：
> **看见排线就是古典，看见干净的几何线与平涂色块就是经典。**
> 或者：**经典是今天印的，古典是三百年前印的。**

**给代码侧的两条建议**（本文不修改代码，仅登记为待办）：
1. `legacy-classic` 的 `visual` 目前是 `legacyVisual('orbit')` ——
   与月光、森语共用同一份装帧，且 `cardBack.composition = 'orbit'`（轨道环）
   属于**月光的视觉语言**。建议改为独立装帧（§1.7 已给出建议值）。
2. `deck:check` A 组已有「装帧真的不同 · 字体互不相同」断言，
   但 5 套 legacy 共用 `legacyVisual`，这条断言目前对 legacy 组无效。
   若采纳 §1.6–1.8 的建议值，可顺带把 A 组的覆盖面扩到 8 套。

### 6.2 ⚠️ 阻塞项一：25 张代表牌**现在放进 `cards/` 会让 `deck:check` 失败**

这是一个**已经存在于上游文档里的矛盾**，不是本文引入的。必须在美术交付前解决。

`scripts/deck-check.ts` E 组同时断言了两件事：

```
check(`${deck.deckId} coverage 落在 none/major/full 三档内`,
      ids.length === 0 || ids.length === 22 || ids.length === 78)
check(`${deck.deckId} 磁盘上没有未登记的牌面`,
      onDisk.every((id) => ids.includes(id)))
```

于是 5 张代表牌进 `public/assets/decks/<deckId>/cards/` 之后：

- **登记**它们 → `ids.length === 5` → 「coverage 落在三档内」**失败**
- **不登记** → 「磁盘上没有未登记的牌面」**失败**

而 18 号文 §12 的 Phase 1 验收又要求「五套 coverage 一律 `none`」。
**三条要求两两互斥，当前无解。**

**三个可选解法**（选型是架构决策，不在本文职责内，仅列出）：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A · 评审目录（推荐）** | 代表牌先交付到 `docs/v2/art-review/<deckId>/major-XX.webp`，不进 `public/`。`cover` / `back` 正常进 `public/`。等 22 张齐了再一次性搬进 `cards/` 并登记 | 零代码改动；Phase 1 的牌桌上仍然显示 `missing` 态（**这本来就是设计意图**，18 号文 §3.3：「一张缺失的牌就该看起来像一个待办事项」） |
| **B · 放宽三档断言** | 允许 `ids.length === 5` 且必须恰好是 `PREVIEW_CARD_IDS` | 在「禁止任意子集」这条守着产品哲学的断言上开一个口子。**不推荐** |
| **C · 独立 preview 字段** | `DeckArtworkManifest` 加 `preview: Record<string,string>`，与 `cards` 分开断言 | 改类型 + 改 resolver + 改 5 份 manifest；且 `DeckDefinition` 字段白名单虽不受影响，但多一个可被误用为「精选牌」的字段 |

> 倾向 **A**：它零代码改动，且完全符合「Phase 1 五套 coverage 一律 `none`」
> 这条已经写死的验收标准。代表牌在 Phase 1 的作用本来就是**横向对比与美术验收**，
> 不是上线渲染。

# 附录 A · 代表牌变更：`major-17` 星星 → `major-06` 恋人

## 为什么换

星星是一张**构图极其对称、留白极大**的牌 —— 恰恰因此它对画风差异不敏感：
八套牌画出来都会是「一片静水 + 一颗星」，差别主要落在色温上。
它是好画的一张，但不是好**比**的一张。

恋人相反：**画面里有两个主体和一个抉择结构**。它同时考验人物造型、
两者之间的空间关系、以及「张力」怎么表达 —— 这三样正是八套牌风格分野最大的地方。
作为横向对照组，它的信息量远高于星星。

`major-17` 的牌义数据与前文那 8 段 brief **全部保留**，Phase 2 补 22 张大阿卡纳时直接用。
本附录只补齐 `major-06` 的 8 段。

## `major-06` The Lovers · 八套 brief

共同约束（与前文一致）：不烘焙文字数字 · 可 180° 阅读 · 边缘 6% 安全区 ·
底部 22% 会被牌名渐变压住 · 牌义/正逆位在八套之间完全一致，只有画在变。

**`ethereal` 空灵**
主体：雾中两个几乎透明的人形轮廓，相距约一个身位，之间没有任何连接物。
构图：两人各占画面左右三分之一，中间的空是主角。
光源：从两人之间的缝隙里透出来的一道竖光。
色彩：灰蓝与白，唯一暖色是那道竖光。
装饰：无。
识别：**两个人之间什么都没有，而那个"没有"是最亮的地方。**

**`elysian` 极乐之影**
主体：两株对称的橄榄树，树冠在顶部交汇成一个尖拱；拱下一条分岔的石径。
构图：完全左右镜像 —— 这是极乐之影的机械规则。
光源：拱顶缝隙漏下的一束斜光，落在分岔点上。
色彩：深绿、近黑、旧金。
装饰：闭合的金线装饰框，四角对称。
识别：**分岔点被照亮，而两条路都在暗处。**

**`opaline` 蛋白潮汐**
主体：一道潮线把画面分成两半，左右两侧的湿沙反射出不同的色相（青 / 品红）；
潮线中点有一枚贝壳，一半在水里一半在岸上。
构图：横向分割，非对称 —— 左侧水多，右侧沙多。
光源：漫射天光，无明确方向。
色彩：同一条带上从青滑到品红，这是蛋白潮汐的唯一识别锚点。
装饰：细银发丝内衬。
识别：**同一片沙，左右两边是两种颜色。**

**`wonderland` 仙境之影**
主体：两扇歪斜的门并排立着，门框不平行；两门之间悬着一把没有指向任何一扇门的钥匙。
构图：透视被拧过 —— 左门的地平线比右门低。
光源：绿金色，来源不明。
色彩：深紫、墨绿、绿金。
装饰：荆棘卡框。
识别：**钥匙不指向任何一扇门。**

**`classic` 经典**
主体：两个人物正面并立，中间偏上是一个几何化的太阳徽记；
两人脚下各有一块颜色不同的地砖（一块酒红、一块象牙）。
构图：中轴对称，规整。
光源：正上方，均匀。
色彩：象牙底，金线，一点酒红。
装饰：金色几何徽记 + 双线内衬。
识别：**浅底 + 规整金色几何 + 一点酒红。**

**`legacy-moonlight` 月光**
主体：夜间水面上并排的两道月光路径，各自通向不同方向；
路径起点重合于画面底部中点。
构图：Y 形，起点合、终点分。
光源：画面上方的一轮完整月亮。
色彩：靛蓝、银。
装饰：一圈完整闭合的银色轨道环。
识别：**靛蓝 + 银圆环 + 两条分开的水上光路。**

**`legacy-classic` 古典**
主体：一枚有厚度、有投影的实体印章，章面上刻着两个相对的侧脸剪影；
章的四周是密集的排线。
构图：印章居中偏上，排线填满其余空间。
光源：左上，靠排线密度表现明暗。
色彩：陈旧象牙、暗金。
装饰：旧版画的排线与压边。
识别：**浅底 + 排线 + 一枚有投影的实体印章。**

**`legacy-forest` 森语**
主体：一株从同一根系长出、在中途分成两支的植物墨线图；
两支各结一枚形状不同的果实，根系画得与枝叶一样详细。
构图：纵向单株，根系占下半部。
光源：无明确光源，纯墨线。
色彩：深绿、墨黑。
装饰：无边框，留白即边框。
识别：**深绿 + 纵向单株 + 同根分两支。**
