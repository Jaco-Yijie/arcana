# Home Entrance V1

## 动画流程

保留既有 Cover；用户进入 Home 后开始计时，不增加等待屏幕。

- 0–1s：背景底色、纹理与光晕淡入。
- 1–2s：墨雾、纹样、月轮、轴线与徽记出现。
- 2–3s：ARCANA 逐字淡入，轻微模糊到清晰、字距收拢；标语延后 0.5s。
- 3–4.1s：三张牌依次上移 16px、淡入、轻微旋转归位。
- 4s 起：CTA 上方出现一次细光线；按钮本体始终可见、可点击，不等待动画。
- 后续：卡牌 8s 轻浮动（4px、±0.35°），预绘制阴影只变透明度；背景缓慢呼吸。

## 实现与修改文件

- `src/styles/home-motion.css`：首页专用时间令牌、CSS 关键帧与媒体降级。
- `src/pages/HomePage.tsx`：卡牌入场/浮动两层容器，品牌逐字 span 与完整无障碍标题，CTA 样式钩子。
- `src/main.tsx`：加载动画样式。
- `tests/design-system.test.ts`：增加 CTA 独立、移动降级、资源不增加的约束检查。

没有新增业务组件或依赖。使用现有 SVG/WebP、CSS transform/opacity；仅桌面标题短时使用 blur 与 letter-spacing。没有 WebGL、视频、粒子或逐帧 React 更新。牌组与占卜行为不变。

## Mobile 与无障碍

375 / 390 / 430：保留整体标题淡入、卡牌上移淡入、背景呼吸；关闭逐字动画、blur、字距动画、持续卡牌浮动与月轮漂移。减少动态或慢刷新设备全部静态呈现。CTA 不设置 disabled、延迟挂载、透明隐藏或点击拦截。键盘聚焦时品牌立即可读。

## 验证

- 完整 `npm run build` 通过（类型、i18n、Deck、布局、资产及设计检查）。
- `npm run design:check`：5 项通过。
- 实际点击：加载后约 23ms 主按钮可见可用，入场完成前成功跳转到引导页。
- 三个手机视口无横向溢出；三张原有 WebP 缩略图均成功加载。
- 减少动态设置生效后，Home 运行中的动画为 0。
- 5s requestAnimationFrame 采样：手机视口 p95 帧间隔 17.4–17.5ms、超过 50ms 的帧为 0；桌面 p95 17.6ms，2 次超过 50ms，最大 266.6ms。测试含页面加载，不将停顿归因于某个动画。

以上是本机 Chromium 的屏幕尺寸模拟，不是低端手机 FPS 保证，也没有做真实模型延迟测试。
